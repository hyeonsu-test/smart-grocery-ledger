# 베타 검증 기록

- 기준일: 2026-11-02
- 환경: Windows, Python 3.10.11, Tkinter 8.6
- 서비스 테스트: 31개 통과 (`python -m unittest discover -s tests -v`)
- 화면 생성: 5개 화면, 가격 이력 9개 행, 목표 3개 행, API 매뉴얼 생성 통과
- 확인 범위: 내역 CRUD·날짜 이동·취소, 저장 실패 보존, 손상 파일 쓰기 차단, 예산 미설정·0원·초과, 계획 초안, 미확정 가격, 5종 단위 환산, 현재 가격 제외, 이력 날짜 중복 제거, 28일 관측일 평균, 개인 목표 우선, 알림 저장 선행·재시작 중복 방지, 수동 입력 검증, 출처별 부분 실패, 자동 갱신 날짜 제한

- 실제 마트 웹 수집기는 미구현이며 JSON 파일 입력만 검증했다.
