# 시연 데이터로 기능 확인하기

발표·평가 또는 개발 중 화면 동작을 확인할 때 사용하는 안내입니다. 예제 수입·지출과 가상 상품 가격을 가진 별도 가계부를 엽니다. 실제 사용 방법은 [사용자 안내](../README.md)를 참고하세요.

## 시연 모드 실행

JAR를 저장한 폴더에서 실행합니다.

~~~sh
java -jar SmartGroceryLedger.jar --demo
~~~

기본 저장 위치는 사용자 홈 폴더의 `SmartGroceryLedger/data/demo.json`입니다. 개인 가계부인 `ledger.json`과 별도 파일을 사용합니다. 처음 실행할 때만 시연 데이터를 생성하고, 같은 시연 파일이 있으면 저장된 내용을 다시 엽니다.

시연 모드에서는 가상 가격을 사용하며 실제 온라인 가격을 수집하지 않습니다. 화면 상단의 **시연 모드 · 가상 가격 / 실제 판매가 아님** 표시를 확인하세요. 상품 검색·자동 수집을 검증하려면 아래의 일반 모드 실행 방법을 사용합니다.

## 새로운 시연 자료 만들기

발표 날짜에 맞는 새로운 예제 데이터가 필요하면 아직 시연 파일이 없는 별도 폴더를 지정합니다. 폴더는 앱이 생성합니다.

~~~sh
java -jar SmartGroceryLedger.jar --demo --data-dir "./demo-new"
~~~

시연 가격과 예제 기록은 그 폴더에서 시연 가계부를 처음 만드는 날짜를 기준으로 생성됩니다. 같은 폴더로 다시 실행하면 기존 `demo.json`을 읽으므로 날짜나 가격을 새로 만들지 않습니다. 다시 처음부터 시연하려면 다른 새 폴더 이름을 지정합니다.

## 실제 수집 흐름 검증

개인 가계부와 분리된 빈 폴더에서 일반 모드로 실행합니다.

~~~sh
java -jar SmartGroceryLedger.jar --data-dir "./verification-new"
~~~

시작 시 기본 목록을 수집하며, 03에서 상품을 검색·확인한 뒤 수집 목록에 등록할 수 있습니다. 04에서 등록한 상품의 실제 단위 가격·이력을 확인하고, 05에서 관심 상품과 개인 목표를 저장한 다음 종료·재실행해 복원을 확인합니다.

실제 가격은 응답 시점의 재고·판매 조건에 따라 달라집니다. 검증에는 수집 시각, 성공·실패, 표시 단위와 저장한 목표를 함께 기록하세요. 처음 수집한 상품은 과거 관측일이 없으므로 개인 목표를 지정하면 첫날부터 알림 조건을 확인할 수 있습니다.

빌드 명령·자동 테스트·기존 플랫폼별 결과는 [빌드와 검증](verification.md)에 있습니다.
